# 🪐 Celestial Bodies Database - freeCodeCamp Relational Database Project

A relational database project built as part of the freeCodeCamp Relational Database Certification. This project demonstrates PostgreSQL database creation, table design, relationships, and data structuring for astronomical objects.

## 📋 Project Overview
The project manages a relational database (`universe`) containing information about:
* **Galaxies:** Our cosmic neighborhoods and types.
* **Stars:** Stellar bodies and their characteristics.
* **Planets:** Major planets orbiting stars.
* **Moons:** Natural satellites orbiting planets.
* **Additional custom table:** Tracking related characteristics or categories.

---

## 🛠️ Tech Stack
* **Database:** PostgreSQL
* **Environment:** Linux / VS Code / CodeRoad

## 📂 Project Files
* `universe.sql` — A complete database dump containing the entire schema, tables, relationships, and inserted data.
